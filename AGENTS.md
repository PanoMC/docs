# AGENTS.md

Entry point for AI coding agents (Claude Code, Codex, Copilot, Gemini …) in the Pano docs repo. It holds no rules of its
own: open the file that fits your task, and only that one.

| You need                                                              | Read                                  |
| --------------------------------------------------------------------- | ------------------------------------- |
| Rules for every Pano repo                                             | `guidelines/README.md`                |
| Panel UI design                                                       | `guidelines/design/README.md`         |
| Plugin, theme or headless front-end rules                             | `guidelines/agent-guide/README.md`    |
| Writing or changing a docs page: structure, sidebar, build            | `README.md`, `.vitepress/config.js`   |
| Agent-facing docs pages (llms.txt, MCP, building with agents)         | `ai/index.md`                         |

`guidelines/` is not part of the published site (`srcExclude` in `.vitepress/config.js`).
