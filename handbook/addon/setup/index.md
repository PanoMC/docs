# Setup

Setup is the same for every addon, so it lives in one place: follow [Addon Getting Started](/addon/getting-started/) and scaffold the addon with the id `pano-plugin-shoutbox` (`bunx @panomc/plugin-kit new pano-plugin-shoutbox`, run inside Pano's `plugins/` folder).

When **Shoutbox** is listed in **Panel → Addons** and its page opens on the site, continue with **[Backend →](/handbook/addon/backend/)**.
