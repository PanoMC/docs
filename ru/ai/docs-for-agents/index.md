# Документация для агентов

Четыре способа дать эту документацию ИИ-агенту. Если ваш инструмент поддерживает MCP, используйте MCP-сервер; файлы работают во всех остальных случаях.

## llms.txt

```text
https://panomc.com/docs/llms.txt
```

Короткий указатель для языковых моделей: каждая страница документации с заголовком и адресом. Дайте его агенту, который умеет открывать URL, и пусть он сам выберет нужные страницы. Это же надёжное место, где можно найти точный адрес страницы.

## llms-full.txt

```text
https://panomc.com/docs/llms-full.txt
```

Вся документация одним файлом Markdown. Используйте его, когда инструмент не умеет открывать сайты: скачайте и приложите файл или добавьте его в знания проекта. Файл большой, поэтому, если вы знаете, какие страницы важны, лучше дать отдельные страницы.

## Страница в Markdown

Каждая страница отдаётся и как обычный Markdown: добавьте `.md` к адресу страницы (без косой черты на конце).

| Страница | Markdown |
|---|---|
| `https://panomc.com/docs/platform/installation/` | `https://panomc.com/docs/platform/installation.md` |

```sh
curl -s https://panomc.com/docs/platform/installation.md
```

Если адрес не отвечает, возьмите точный адрес из `llms.txt`.

## MCP-сервер

`https://panomc.com/mcp` это сервер Model Context Protocol для этой документации. Транспорт: Streamable HTTP. Без входа. Только чтение: он не видит и не может изменить ни один сайт Pano.

| Инструмент | Вход | Возвращает |
|---|---|---|
| `search_docs` | запрос | подходящие страницы |
| `get_doc` | путь страницы | эту страницу в Markdown |

### Claude Code

```sh
claude mcp add --transport http pano-docs https://panomc.com/mcp
```

### Cursor и другие клиенты

Добавьте сервер в настройку MCP клиента (в Cursor: `.cursor/mcp.json` в проекте):

```json
{
  "mcpServers": {
    "pano-docs": { "url": "https://panomc.com/mcp" }
  }
}
```

### VS Code

VS Code использует ключ `servers` и требует тип (`.vscode/mcp.json` в проекте):

```json
{
  "servers": {
    "pano-docs": { "type": "http", "url": "https://panomc.com/mcp" }
  }
}
```

Любой другой клиент, который поддерживает удалённые MCP-серверы по Streamable HTTP, работает с тем же адресом.

## Проверьте

```text
Используй инструменты pano-docs. Какой заголовок сервер отправляет в Pano, чтобы представиться,
и где в панели создать этот ключ? Назови страницу, с которой взят ответ.
```

Правильный ответ называет `X-Pano-Frontend-Key` и путь в панели со страницы [Доступ](../../integration/access/). Если агент отвечает, не вызывая `search_docs` или `get_doc`, скажите ему использовать инструменты: ответ по памяти часто устарел.

## Советы

- Просите агента **назвать страницу**, которой он пользовался. Тогда её можно открыть и проверить.
- Эта документация описывает Pano в целом. Для API **вашего** сайта с вашими плагинами дайте агенту ваш собственный документ OpenAPI: см. [API Pano и агент](../using-pano/).
- В репозитории плагина, темы или стартового шаблона агент должен сначала прочитать папку `agent-guide/`: см. [Разработка с агентом](../building/).
