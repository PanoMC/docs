# Pano и ИИ-агенты

Разрабатывать для Pano можно вместе с ИИ-агентом для программирования: Claude Code, Cursor, Codex, GitHub Copilot или любым другим инструментом, который читает файлы и запускает команды. Этот раздел показывает, что Pano даёт такому инструменту для чтения и как просить у него плагин, тему, headless-сайт или скрипт.

Агент хорош ровно настолько, насколько хорошо то, что он читает. Пакеты Pano молодые и часто меняются, поэтому агент, отвечающий по памяти, будет угадывать. Направьте его к источникам ниже.

## Что доступно

| Что | Где | Зачем |
|---|---|---|
| Указатель страниц для LLM | `https://panomc.com/docs/llms.txt` | Список всех страниц документации с адресами |
| Вся документация одним файлом | `https://panomc.com/docs/llms-full.txt` | Вставьте или приложите, если инструмент не умеет открывать сайты |
| Каждая страница в Markdown | адрес страницы с `.md` на конце | Дать агенту одну конкретную страницу |
| MCP-сервер документации | `https://panomc.com/mcp` | Агент сам ищет и читает документацию |
| Руководство для агентов в репозиториях-шаблонах | `AGENTS.md`, `CLAUDE.md` и `agent-guide/` | Правила написания плагина, темы или headless-сайта |
| Документ OpenAPI вашего Pano | `/api/v1/openapi.json` на вашем сайте | Точный API вашего сайта, включая плагины |

## Настройка за минуту

Подключите документацию к агенту один раз. В Claude Code:

```sh
claude mcp add --transport http pano-docs https://panomc.com/mcp
```

В Cursor и большинстве других инструментов добавьте это в файл настройки MCP:

```json
{
  "mcpServers": {
    "pano-docs": { "url": "https://panomc.com/mcp" }
  }
}
```

Серверу не нужен вход, и он умеет только читать документацию. Вариант для VS Code и что делать, если ваш инструмент не поддерживает MCP, описаны в разделе [Документация для агентов](./docs-for-agents/).

Затем задайте вопрос, чтобы проверить, что всё работает:

```text
Используй инструменты pano-docs. Как начать новую тему Pano и какой файл править, чтобы сменить основной цвет?
```

В ответе должны быть `bunx @panomc/theme-core new` и `src/styles/tokens.scss`, как на странице [Начало работы с темой](../theme/getting-started/).

## Чего агент за вас не сделает

- **Он не заменяет работающий Pano.** Плагин и тема разрабатываются на вашем собственном Pano с включённым режимом разработки. См. [Установка Pano](../platform/installation/).
- **Он не управляет вашим сайтом.** У Pano нет MCP-сервера, который изменяет сайт. Единственный MCP-сервер работает только на чтение и только с этой документацией. До работающего Pano агент добирается лишь через HTTP API и с тем доступом, который вы ему дали: см. [API Pano и агент](./using-pano/).
- **Он не выпускает релиз за вас.** Перед публикацией прочитайте diff, запустите проверки и попробуйте результат в браузере. Каждая страница этого раздела заканчивается списком того, что нужно проверить вручную.
