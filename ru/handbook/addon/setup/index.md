# Настройка

Настройка одинакова для каждого дополнения, поэтому она в одном месте: следуйте [Началу работы с дополнением](/ru/addon/getting-started/) и создайте дополнение с id `pano-plugin-shoutbox` (`bunx @panomc/plugin-kit new pano-plugin-shoutbox` в папке `plugins/` Pano).

Когда **Shoutbox** появится в **Панель → Дополнения**, а его страница откроется на сайте, продолжайте с **[Бэкенд →](/ru/handbook/addon/backend/)**.
