# Настройка

Настройка одинакова для каждой темы, поэтому она в одном месте: следуйте [Началу работы с темой](/ru/theme/getting-started/) и назовите тему `ember` (`bunx @panomc/theme-core new ember`).

Когда Ember появится по адресу вашего Pano, а `src/styles/tokens.scss` будет открыт, продолжайте с **[Дизайн и стили →](/ru/handbook/theme/design/)**.
