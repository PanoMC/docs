# Использование Pano за Coolify или Traefik

[Coolify](https://coolify.io/) пропускает каждый сайт через свой прокси, **Traefik v3**. Traefik v3 обрывает любой
запрос, тело которого идёт дольше **60 секунд** (`respondingTimeouts.readTimeout`). У самого Pano нет ограничений на
размер и время загрузки, поэтому упираетесь вы именно в этот предел: архив сервера на 600 МБ по каналу 50 Мбит/с идёт
около 100 секунд и обрывается на середине, а панель сообщает, что загрузка прервана. Скачивание это не затрагивает.

## Увеличьте тайм-аут чтения

В Coolify откройте **Servers → ваш сервер → Proxy**, добавьте эти две строки в `command` прокси, сохраните и
перезапустите прокси:

```yaml
command:
  # … существующие строки остаются …
  - '--entrypoints.http.transport.respondingTimeouts.readTimeout=6h'
  - '--entrypoints.https.transport.respondingTimeouts.readTimeout=6h'
```

Перезапуск прокси на несколько секунд прерывает все сайты на этом сервере. Шести часов хватает для многогигабайтных
загрузок по медленным каналам; передачу, которая перестала двигаться, Pano всё равно завершает через пять минут без
данных.

Если Traefik настроен вручную, задайте то же значение для точки входа, через которую работает Pano, в статической
конфигурации:

```yaml
entryPoints:
  websecure:
    transport:
      respondingTimeouts:
        readTimeout: 6h
```
