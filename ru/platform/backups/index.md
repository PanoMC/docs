# Резервные копии

> Находятся на странице **Резервные копии** вашей панели. Для Pano Backup нужен подключённый аккаунт Pano
> (**Панель → Настройки → Платформа** или шаг с аккаунтом в мастере установки).

Резервная копия содержит всё, что делает Pano вашим: базу данных, настройки, плагины, темы и загруженные
файлы. Pano хранит копии в двух местах: **на вашем сервере** и в **Pano Backup** — облачном хранилище,
которое входит в ваш аккаунт Pano.

## Pano Backup {#pano-backup}

Pano Backup хранит копии вне вашего сервера, поэтому сломанный диск или потерянный сервер не унесёт их с собой.

- **Бесплатно для всех.** У каждого аккаунта есть **1 ГБ** бесплатного хранилища. Более крупный тариф можно
  выбрать на сайте Pano. Хранилище общее для всех Pano, подключённых к аккаунту.
- **Ежедневно с первого дня.** На шаге с аккаунтом в мастере установки есть пункт **Ежедневная копия с
  бесплатным Pano Backup**. Отметьте его, и Pano будет создавать копию каждый день с момента установки. Уже
  установили? Откройте **Настройки резервного копирования** на странице копий, поставьте **Расписание Pano
  Backup** в **Ежедневно** (или Еженедельно) и выберите час.
- **Без ограничений по количеству и сроку.** Копии хранятся, пока вы их не удалите или не заполнится
  хранилище. Pano сам старые копии не удаляет.
- **Создать сейчас.** Кнопка **Сохранить в Pano Backup** запускает копию в любой момент.

### Тип копии {#backup-type}

В **Настройки резервного копирования → Тип копии** вы выбираете, как работает Pano Backup:

| Тип | Что делает |
| --- | --- |
| **Снимок** (по умолчанию) | Отправляет только то, что изменилось с прошлого раза, поэтому ежедневные копии занимают совсем немного места. Каждый снимок можно восстановить отдельно. |
| **Полный архив** | Каждый раз отправляет весь сайт. Занимает больше места и может быть защищён вашим паролем (**Пароль шифрования**). Если вы потеряете этот пароль, такие архивы больше не открыть. |

Снимки не защищаются вашим собственным паролем.

### Когда хранилище заполнено {#storage-full}

Когда хранилище почти заполнено и когда оно заполнилось, вы получаете предупреждение **по e-mail и в
уведомлении**. Заполненное хранилище не принимает новые копии, а отклонённая копия ничего после себя не
оставляет. Удалите ненужные копии или выберите тариф побольше.

## Восстановление {#restoring}

На странице копий нажмите **Восстановить** рядом с копией. Затем Pano:

1. запрашивает ваш **текущий пароль**,
2. переходит в [режим обслуживания](../maintenance/),
3. сначала создаёт **страховочную копию** текущего состояния,
4. заменяет базу данных, настройки, плагины, темы и загруженные файлы данными из копии,
5. перезапускается. Если что-то пойдёт не так, страховочная копия будет возвращена.

Так можно восстановить любой готовый снимок вашего аккаунта, в том числе сделанный другим вашим Pano.
Восстановление заменяет текущие данные Pano, поэтому используйте его осторожно.

## Удаление и скачивание {#download}

- **Удалить** навсегда убирает копию из Pano Backup. Остальные копии не меняются.
- Копию можно **скачать** на странице **Pano Backup** вашего аккаунта на сайте Pano. Там один список всех
  ваших копий с указанием, к какому Pano относится каждая, и можно скачать или удалить любую из них. Снимок
  упаковывается для вас и приходит одним файлом **`.panoarc`**.
- Файл `.panoarc` — тот же однофайловый формат, что использует полный архив. Храните его где угодно и
  восстанавливайте через **Восстановить из файла** на странице копий или через **Восстановить из файла
  резервной копии** в мастере установки нового Pano.

Если браузер не может сохранить большую копию, восстановите её из панели самого Pano.

## Копии на вашем сервере {#local}

**Создать копию** записывает копию на ваш сервер. Их тоже можно запускать по расписанию (**Расписание
локальных копий**); из копий по расписанию хранятся только самые новые, а созданные вручную никогда не
удаляются автоматически. Локальные копии можно зашифровать своим паролем. Формат архива описан в разделе
[Эксплуатация instance](../hosting/operations/#backups).
