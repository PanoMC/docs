# Шаблоны писем

Любое письмо, которое отправляет Pano, — и письма самой платформы, и письма ваших плагинов — можно переписать из
панели на каждом языке вашего сайта. Откройте **Панель → Настройки → Шаблоны писем**. Сама отправка (SMTP или Pano Mail)
настраивается в разделе [Сервисы → Электронная почта](../services/#электронная-почта-smtp).

Нужно разрешение **Управление шаблонами писем**. Каждое сохранение и сброс записываются в журнал активности.

## Что можно редактировать

Страница группирует письма по отправителю:

- **Платформа:** активация аккаунта, подтверждение смены почты, пароль изменён, сброс пароля, блокировка и оповещения
  о серверах.
- **Плагины:** каждый установленный и запущенный плагин, который отправляет письма, например ссылка для входа из Auth
  Guard, письмо о смене имени пользователя из Premium Login и письма магазина из Market. Пока плагин остановлен, его
  письма пропадают из списка.

У некоторых писем есть **варианты**: одно письмо с отдельным текстом для каждой ситуации. У оповещений о серверах по
варианту на каждое оповещение (сервер упал, узел офлайн, ошибка бэкапа, мало места на диске, низкий TPS, ошибка задачи
по расписанию, обновления плагинов); у Market — по варианту на каждое письмо о заказе, подписке и доставке. У писем без
таких видов один вариант — **По умолчанию**.

За раз вы редактируете одну комбинацию **письмо × вариант × язык**. Языки, которые вы изменили, отмечены значком.

## Редактор

Общий вид (логотип, белая карточка, кнопка, строка подвала) задаёт макет, поэтому шаблон — это только тексты:

| Поле | Что это |
| --- | --- |
| **Тема** | Строка темы (обязательно, не больше 255 символов) |
| **Прехедер** | Короткая строка, которую почтовые программы показывают рядом с темой; в самом письме скрыта |
| **Текст** | Само сообщение, в визуальном редакторе |
| **Текст / URL кнопки** | Главная кнопка; оставьте URL пустым, если кнопка не нужна |
| **Подвал** | Небольшая заметка под карточкой, например «Если вы этого не запрашивали, просто проигнорируйте письмо» |

::: v-pre

**Вставка переменных.** В боковом списке — то, что знает выбранное письмо (имя пользователя, ссылки, суммы…). Нажмите
на переменную, и она встанет на место курсора: в редакторе это плашка, в шаблоне — `{{username}}`. Переменные работают
в любом поле, включая тему и URL кнопки. Некоторые переменные — готовые **блоки**, которые собирает плагин, например
таблица товаров или реквизиты для банковского перевода в Market; они вставляются как `{{{items}}}` (три фигурные скобки)
и должны стоять на отдельной строке.

В каждом письме доступны: `{{websiteName}}`, `{{websiteUrl}}`, `{{websiteLogo}}`, `{{year}}`, `{{locale}}`.

**Расширенный режим (HTML).** Вкладка **Расширенный** показывает текст как HTML с Handlebars — для того, что не умеет
визуальный редактор, например `{{#if exitCode}}…{{/if}}`, чтобы показать фразу только при наличии значения. Если
переключить письмо в **полный HTML**, текст становится самостоятельным HTML-документом и отправляется без общего макета.


**Handlebars.** Все поля, текст письма, полный HTML и макет — это шаблоны [Handlebars](https://handlebarsjs.com/guide/):
`{{name}}` выводит переменную, `{{{name}}}` — готовый HTML-блок, `{{#if name}}…{{else}}…{{/if}}` показывает часть только
при наличии значения, `{{#each list}}…{{/each}}` повторяет часть. Работают только встроенные хелперы (`if`, `unless`,
`each`, `with`, `lookup`); собственные хелперы недоступны. Полный синтаксис — в
[руководстве Handlebars](https://handlebarsjs.com/guide/).
:::

**Предпросмотр** показывает несохранённые изменения с примерами значений — вы видите письмо раньше получателей.
**Отправить тестовое письмо** шлёт этот предпросмотр на ваш адрес; нужна работающая почта, и если отправка выключена или
Pano Mail недоступен, вы об этом узнаете. **Сохранить** сначала проверяет шаблон и указывает на поле с ошибкой (пустая
тема, слишком длинная тема или Handlebars, который не компилируется).

**Сбросить к стандартному** удаляет вашу версию для этого языка, и возвращается текст по умолчанию.

### Макет

::: v-pre

**Редактировать макет** открывает единый HTML-макет, в который оборачивается каждое письмо: шапка с логотипом, карточка,
кнопка и подвал. Своего текста в нём нет, поэтому один макет подходит для всех языков. В нём обязательно должен остаться
слот `{{{content}}}`, куда попадает текст письма. **Сбросить к стандартному** возвращает макет Pano.

:::

## Какой язык отправляется

Письмо уходит на языке получателя (язык его аккаунта, иначе язык сайта). Для этого языка Pano берёт первый найденный
текст:

1. вашу отредактированную версию на этом языке,
2. текст по умолчанию на этом языке,
3. текст по умолчанию на базовом языке (`pt-BR` → `pt`),
4. вашу отредактированную английскую (`en-US`) версию,
5. английский текст по умолчанию.

Значит, язык, добавленный в **Панель → Переводы**, отправляет письма на английском, пока вы не напишете для него шаблоны
здесь; в редакторе он открывается с английским текстом, и редактор сообщает, с какого языка взят вариант по умолчанию.

## Обновления

Ваши правки хранятся в базе данных и переживают обновления Pano и плагинов. Если обновление приносит новый текст по
умолчанию, вы увидите его только на языках, которые не меняли; чтобы взять новый текст на изменённом языке, нажмите
**Сбросить к стандартному**.
