# Установка Pano

Следуйте этому руководству, чтобы настроить **Pano** и запустить его всего за несколько минут.

## Быстрый старт {#quick-start}

Рекомендуемый способ — [установка одной командой](installer/). Она устанавливает Pano, его собственную
Java, службу и команду `pano`:

::: code-group

```bash [Linux / macOS]
curl -fsSL https://panomc.com/install | bash
```

```powershell [Windows]
powershell -c "irm https://panomc.com/install.ps1 | iex"
```

:::

Добавьте `--mariadb` (в Windows: `-MariaDB`), и она установит ещё и базу данных для Pano. Затем откройте
`http://localhost` (или адрес, который выведет установщик) и пройдите [мастер настройки](setup/).

## Выбор способа {#methods}

| Способ | Кому подходит | Что нужно от вас |
| --- | --- | --- |
| [Установка одной командой](installer/) (рекомендуется) | Большинство серверов и ваш компьютер | Ничего; MariaDB по желанию (`--mariadb`) |
| [Docker](../containers/) | Серверы, где уже работает Docker | Docker с плагином compose |
| [Вручную, `.jar`](manual/) | Полный контроль или панель, которая запускает только `.jar` | Java 11+, база данных, свой скрипт запуска |

Не хотите держать сервер? [Pano Host](https://panomc.com/host) запустит Pano за вас.

Все три способа заканчиваются одинаково: [мастером настройки](setup/) в браузере.

## Требования {#requirements}

1. **Java 11 или новее**
   - Только для ручной установки `.jar`: установщик загружает собственную Java, а образ Docker уже содержит её.
   - Локальный `pano-node` для [управляемых серверов](../server-management/managed-servers/) работает на
     той же Java, ничего дополнительно не требуется.

2. **MySQL 5.5+ или MariaDB**
   - Для хранения данных требуется база данных MySQL или MariaDB.
   - Установщик создаёт её с `--mariadb`; Docker Compose запускает её рядом с Pano.
   - Префикс таблиц по умолчанию: `pano_` (вы можете изменить его во время настройки).

3. **Подключение к Интернету**
   - Требуется во время настройки: при первом запуске Pano загружает интерфейс и зависимости.

4. **Открытый порт**
   - Установщик, Docker и запущенный вручную `.jar` обслуживают Pano на порту **80**.
     Установщик переходит на **8088**, если порт 80 занят или если в Linux он ставит Pano для одного
     пользователя (там порт 80 доступен только системной установке).
   - **Дополнительно:** если вы настроите SSL после установки, порт **443 (HTTPS)** также должен быть открыт.

5. **Операционная система**
   - Установщик работает в Linux, macOS и Windows. `.jar` работает везде, где есть Java.

## После установки {#after-installation}

- Пройдите [мастер настройки](setup/) и [подключите ваш сервер Minecraft](setup/#connect-minecraft).
- При необходимости измените файл конфигурации: [Руководство по настройке →](../configuration/).
