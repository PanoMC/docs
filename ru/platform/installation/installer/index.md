# Установка одной командой

Одна команда устанавливает Pano со всем, что ему нужно: релиз Pano, собственную среду Java, загрузчик,
который перезапускает Pano после сбоя, службу, запускающую его вместе с системой, и команду `pano`. Всё,
что записывает Pano, остаётся в одной папке.

## Запуск {#run}

::: code-group

```bash [Linux / macOS]
curl -fsSL https://panomc.com/install | bash
```

```powershell [Windows]
powershell -c "irm https://panomc.com/install.ps1 | iex"
```

:::

Нет `curl`? Используйте `wget -qO- https://panomc.com/install | bash`. В Linux и macOS нужны `curl` или
`wget`, а также `tar`. [Страница загрузок](https://panomc.com/downloads) соберёт команду за вас.

Установщик сначала спрашивает язык (английский, турецкий или русский), затем показывает экран
параметров: **Вверх / Вниз** — перемещение, **Enter** — изменить строку или начать установку, **q** —
выход. С `-y` или без терминала он ничего не спрашивает и устанавливает с настройками по умолчанию и
переданными параметрами.

После установки откройте `http://localhost:8088` (или `http://<ip-вашего-сервера>:8088`) и пройдите
[мастер настройки](../setup/).

## Параметры {#options}

Параметры указываются после `bash -s --`; в Windows скрипт запускается как script block:

```bash
curl -fsSL https://panomc.com/install | bash -s -- --mariadb --version 1.0.0
```

```powershell
powershell -c "& ([scriptblock]::Create((irm https://panomc.com/install.ps1))) -MariaDB -Version 1.0.0"
```

| Linux / macOS | Windows | Что делает |
| --- | --- | --- |
| `--mariadb` | `-MariaDB` | Устанавливает MariaDB и создаёт для Pano базу данных и пользователя `pano` |
| `--docker` | — | Запускает Pano и MariaDB в контейнерах. См. [Режим Docker](#docker) |
| `--gui` | `-Gui` | Запускает Pano с окном, а не скрыто в фоне |
| `--version <версия>` | `-Version` | Устанавливает эту версию. По умолчанию: последняя |
| `--channel <канал>` | `-Channel` | Последняя версия канала: `release`, `beta` или `alpha` |
| `--system`, `--user` | `-System`, `-User` | Установка для всей системы или только для текущего пользователя |
| `--dir <папка>`, `--here` | `-Dir`, `-Here` | Установка в эту папку или в текущую |
| `--port <порт>` | `-Port` | Порт, который слушает Pano. По умолчанию: `8088` |
| `--java <версия>` | `-Java` | Java, на которой работает Pano: `11` (по умолчанию), `17`, `21` или `25` |
| `--system-java` | — | Устанавливает эту Java в систему через менеджер пакетов, а не в папку Pano |
| `--memory <объём>` | `-Memory` | Максимум памяти для Java Pano, в МБ или ГБ (`1024`, `2g`). По умолчанию `1g`, не меньше `512` |
| `--no-restart` | `-NoRestart` | Не перезапускать Pano после сбоя |
| `--no-autostart` | `-NoAutostart` | Не запускать Pano при старте системы |
| `--lang <en\|tr\|ru>` | `-Lang` | Язык установки |
| `-y`, `--yes` | `-Yes` | Ничего не спрашивать |
| `-h`, `--help` | `-Help` | Показать параметры |

- **Версия:** без `--version` и `--channel` ставится последний стабильный релиз; пока его нет —
  последняя бета, иначе последняя альфа. Загруженный файл проверяется по SHA-256.
- **Область:** при запуске от root / администратора установка выполняется для всей системы, иначе — для
  текущего пользователя. Системная установка запрашивает `sudo` (в Windows — права администратора).
- **Память:** при объёме меньше 1 ГБ Pano запустится, но памяти может не хватить.

## Что устанавливается {#what-it-installs}

| | Текущий пользователь | Вся система |
| --- | --- | --- |
| Папка в Linux / macOS | `~/pano` | `/opt/pano` |
| Папка в Windows | `%USERPROFILE%\Pano` | `C:\Pano` (системный диск) |
| Команда `pano` в Linux / macOS | `~/.local/bin/pano` | `/usr/local/bin/pano` |

В папке: `Pano-<версия>.jar`, среда Java в `runtime/jre`, загрузчик и команда `pano` в `bin/`, файл
настроек `pano.env` и всё, что Pano создаёт сам (`config.conf`, `plugins/`, `themes/`, `logs/`, …).

- **Служба:** юнит systemd `pano` в Linux, задание launchd `com.panomc.pano` в macOS, запланированная
  задача `Pano` в Windows. В Linux без systemd службы нет: после перезагрузки запускайте Pano сами
  командой `pano start`. С `--gui` в Linux вместо службы создаётся ярлык в меню приложений.
- **Сбои:** загрузчик перезапускает Pano после сбоя не более 5 раз за 5 минут и никогда — после
  остановки, которую запросили вы. Перезапуски и обновления из панели тоже идут через него.
- **`--mariadb`:** использует системный менеджер пакетов в Linux, Homebrew в macOS и `winget` в Windows.
  Пароль записывается в `pano.env`, а шаг базы данных в мастере настройки уже заполнен. Если MariaDB
  настроить не удалось, Pano всё равно установится, и мастер спросит базу данных.
- **`pano.env`:** `PANO_MEMORY` и `PANO_JVM_ARGS` читаются при каждом запуске. Порт и база данных
  копируются в `config.conf` только при первом запуске; позже меняйте их в панели.
- **Обновление:** запустите установщик снова в той же папке. Pano обновится, ваши данные сохранятся.

## Режим Docker {#docker}

`--docker` (Linux и macOS; нужен Docker с плагином compose) устанавливает только два контейнера: Pano и
MariaDB. Он записывает `compose.yaml` и `.env` (пароль базы данных, тег образа, порт, лимит памяти) в
папку установки (по умолчанию `~/pano`), загружает образы и запускает их. Java, служба и команда `pano`
не устанавливаются: выполняйте в этой папке `docker compose ps`, `logs -f`, `stop` или `up -d`, а чтобы
удалить всё вместе с данными — `docker compose down -v`. См. [Установка через Docker](../../containers/).

## Команда `pano` {#pano-command}

| Команда | Что делает |
| --- | --- |
| `pano start`, `pano stop`, `pano restart` | Запускает, останавливает или перезапускает Pano |
| `pano status` | Запущен ли он? |
| `pano logs` | Показывает журнал в реальном времени |
| `pano dir` | Выводит папку установки |
| `pano uninstall` | Удаляет Pano |

В Windows сначала откройте новый терминал. Если установщик сообщил, что папки команды нет в `PATH`,
вызывайте `<папка>/bin/pano`.

## Удаление {#uninstall}

`pano uninstall` удаляет программу, её среду Java, службу и команду `pano` и **сохраняет ваши данные**
(настройки, плагины, темы, загруженные файлы). Добавьте `--purge` (в Windows: `-Purge`), чтобы удалить и
данные. MariaDB и база данных `pano` никогда не удаляются.
