# Мастер настройки

![](/img/installer-view.png)

После запуска Pano откройте браузер и перейдите по адресу:

```
http://<ip-вашего-сервера>/
```

> Адрес зависит от способа установки: [установщик](../installer/) и [Docker](../../containers/) используют порт **8088** (`http://<ip-вашего-сервера>:8088/`), запущенный вручную [`.jar`](../manual/) — порт **80**. Убедитесь, что этот порт открыт и не используется другим приложением.

> Устанавливали с `--mariadb` или через Docker Compose? Шаг базы данных уже заполнен; оставьте поле пароля пустым, чтобы сохранить его.

> [!IMPORTANT]
> **Используете Cloudflare?** Pano по умолчанию обслуживает обычный HTTP на порту 80, поэтому в Cloudflare необходимо установить **режим SSL/TLS: Flexible** — иначе при открытии вашего домена вы получите циклы редиректов или ошибки `521`/`525`. Перед продолжением ознакомьтесь с отдельным [руководством по Cloudflare →](../../advanced/cloudflare/).

Вы увидите **Мастер настройки**, который проведет вас через пять простых шагов:

1. **Выбор языка и режима использования**  
   Выберите предпочтительный язык, а затем ответьте на вопрос **"Как вы будете использовать Pano?"** на том же экране:
   - **Веб-сайт** — только публичный сайт (классический вариант Pano).
   - **Управление серверами** — только управление серверами Minecraft: продуктом становится панель, **Посты**, **Тикеты** и **Просмотр** (темы) отключаются, а публичные страницы перенаправляются на `/panel`.
   - **Оба варианта** — веб-сайт + управление серверами. Рекомендуется и выбран по умолчанию.

   Выбор не окончательный — позже его можно изменить в разделе **Панель → Настройки → Платформа → Предпочтения**. В `config.conf` он хранится как ключ [`usage-mode`](../../configuration/#общие-настроики).  
   <small>*(Продолжая, вы соглашаетесь с Условиями использования и Политикой конфиденциальности Pano.)*</small>

2. **Конфигурация веб-сайта**  
   Настройте данные вашего сайта (название сайта, URL и т. д.).  
   В режиме **Управление серверами** этот шаг запрашивает **название панели** вместо названия сайта, а поле описания скрыто.

3. **Настройка базы данных**  
   Введите учетные данные **MySQL** или **MariaDB**.  
   Префикс таблиц по умолчанию: `pano_` (при необходимости его можно изменить).  
   > **Портативная БД:** В Windows, macOS и Linux (x64, ARM и большинство других архитектур) вы увидите опцию использования **Портативной базы данных**. При выборе этого варианта Pano автоматически загрузит, настроит и будет управлять портативным экземпляром MariaDB за вас.

4. **Настройки SMTP (необязательно)**  
   Настройте отправку электронной почты, если хотите.  
   Этот шаг является **необязательным**, и если вы решите его пропустить — **не беспокойтесь!**  
   Вы всегда можете включить или обновить настройки SMTP позже в разделе **Панель → Настройки → Платформа**.  
   *(Однако некоторые функции, такие как восстановление пароля, могут не работать до настройки SMTP.)*  
   Нет почтового сервера? Выберите здесь **Pano Mail**: войдите с аккаунтом Pano, и почта заработает сразу, бесплатно и без настройки. См. [Pano Mail](../../configuration/services/#pano-mail).

5. **Привязка аккаунта и создание администратора**
   - Если у вас уже есть **Pano Account**, вы можете привязать его здесь, нажав кнопку **connect** — ваш e-mail и имя пользователя заполнятся автоматически.
   - В противном случае создайте новый **аккаунт администратора** (не забудьте пароль — он понадобится для входа!).
   - Если аккаунт привязан, отметьте **Ежедневная копия с бесплатным Pano Backup**, чтобы копии создавались каждый день с первого дня. См. [Резервные копии](../../backups/).

> Переезжаете с другого Pano? Кнопка **Перенести** в мастере предлагает **Восстановить из файла резервной копии**: выберите файл `.panoarc`, и Pano восстановит этот сайт. См. [Резервные копии](../../backups/#download).

Чтобы завершить настройку, нажмите **Finish**.  
Pano завершит установку и автоматически перенаправит вас в вашу новую **панель администратора**.

> *Теперь вы сможете создавать записи, подключать ваш сервер Minecraft, устанавливать аддоны, менять темы и многое другое!*

## Подключение вашего сервера Minecraft (необязательно) {#connect-minecraft}

Чтобы включить интеграцию с игрой и подключить ваш сервер Minecraft к Pano, вам потребуется установить **Pano MC Plugin**.

### Что такое Pano MC Plugin?

Pano MC Plugin выступает в качестве моста между вашим сервером Minecraft и Pano, обеспечивая:
- Безопасную WebSocket-связь (шифрование RSA + AES-256)
- Синхронизацию данных игроков в реальном времени
- Автоматическое обнаружение и интеграцию плагинов (AuthMe, права доступа и т. д.)
- Систему событий для связи игры с веб-сайтом

### Шаги по установке

1. **Скачивание плагина**
   - Посетите страницу [релизов Pano MC Plugin](https://github.com/PanoMC/pano-mc-plugin/releases)
   - Скачайте подходящий JAR-файл для вашей серверной платформы:
     - `pano-spigot-<version>.jar` — Для Spigot/Paper/Folia
     - `pano-bungeecord-<version>.jar` — Для Bungeecord
     - `pano-velocity-<version>.jar` — Для Velocity
     - `pano-fabric-<version>.jar` — Для Fabric (кладётся в папку `mods/`)

2. **Установка плагина**
   - Поместите скачанный JAR-файл в папку `plugins/` вашего сервера
   - Перезапустите сервер Minecraft

3. **Подключение к Pano**
   - После перезапуска откройте **панель администратора Pano**
   - Откройте **переключатель серверов** в верхней панели
   - Нажмите кнопку **+** рядом с ним, чтобы добавить новый сервер
   - Появится окно подключения с пошаговыми инструкциями
   - Следуйте шагам, показанным в окне, чтобы привязать ваш сервер Minecraft
   - Плагин автоматически установит безопасное зашифрованное соединение

4. **Проверка соединения**
   - После подключения ваш сервер появится в списке переключателя серверов
   - Вы должны увидеть статус сервера (онлайн/оффлайн), количество игроков и другую информацию
   - Соединение теперь активно и готово к интеграциям

> **Примечание:** Вы можете подключить несколько серверов Minecraft к одному экземпляру Pano.

Поддерживаемые платформы: Spigot, Paper, Folia, Purpur, Bungeecord, Velocity и Fabric.

### Что дальше?

Как только ваш сервер будет подключен, вы сможете:
- Включить [интеграции с игрой](../../integrations/) (например, AuthMeReloaded)
- Просматривать статистику игроков в реальном времени
- Управлять игроками из веб-панели
- Синхронизировать игровые события с вашим веб-сайтом
