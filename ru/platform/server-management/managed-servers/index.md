# Управляемые серверы

Управляемый сервер Pano устанавливает и запускает на **узле** — машине, на которой работает демон
[`pano-node`](../pano-node/). Узел сам соединяется **наружу** с Pano, поэтому открывать на нём порты
не нужно. Узлами управляют через **значок узла** рядом с переключателем серверов; нужно право
**Управление узлами**.

## Добавление узла {#adding-a-node}

У **Добавить узел** четыре вкладки:

| Вкладка | |
| --- | --- |
| **Локально** | Собственная машина Pano, в один щелчок. Нужна Java 17+. Файлы лежат в `<pano-dir>/node-data/`, журнал — в `<pano-dir>/logs/pano-node.log`. |
| **Вручную** | Любая машина: выполните показанную однострочную команду, затем одобрите узел. |
| **SSH** | Pano выполняет установку за вас по SSH, после того как вы подтвердите ключ хоста. Учётные данные не сохраняются. |
| **Coolify** | Разворачивает контейнер `ghcr.io/panomc/pano-node` с томом `/data` и игровыми портами. |

Команда на вкладке **Вручную** выглядит так (код меняется каждые 30 секунд):

```bash
curl -fsSL https://panel.example.com/api/node/install.sh | sh -s -- --pano 'https://panel.example.com' --code '123456'
```

Принимайте только те узлы, которые настроили сами. Если узел не может достучаться до адреса вашего
сайта (NAT, SSH-туннель), задайте **Адрес Pano, доступный с узла** в разделе **Дополнительно**.

Узел со старым демоном помечается значком **Есть обновление**; обновление занимает несколько секунд,
а его серверы продолжают работать. **Удаление узла удаляет все серверы и резервные копии на нём.**

## Создание сервера {#creating-a-server}

**Добавить сервер → Создать новый сервер** (нужно право **Создание серверов**) проводит через шаги
**Источник → Узел → Ядро → Настройки → Проверка**.

- **Ядро:** Paper (рекомендуется), Purpur, Folia, Spigot, Fabric, Vanilla и прокси Velocity
  (рекомендуется), Waterfall и BungeeCord. **Spigot** собирается на узле с помощью BuildTools —
  первая сборка версии занимает около десяти минут, следующие берут её из кеша.
- **Настройки:** имя, память, порт (пусто = свободный из `25565-25600`), версия Java, аргументы JVM,
  **Запускать вместе с Pano**, **Перезапуск после сбоя**, **Белый список** (по умолчанию выключен;
  нет для импорта и прокси) и Minecraft EULA.
- Узел скачивает сервер, ставит уже сопряжённый плагин Pano и оставляет сервер в состоянии
  **Остановлен**, готовым к запуску.
- На **Fabric** и **Quilt** моду Pano нужен Fabric API, поэтому узел ставит и его (сборку для этой
  версии Minecraft с Modrinth), если на сервере его ещё нет. Мод Pano требует Minecraft 26.1+;
  на более старых версиях или без сборки Fabric API он не ставится, и задача сообщает об этом.

**Импорт:** в качестве источника можно также выбрать **существующую папку на узле** (копируется,
никогда не перемещается), **загрузку `.zip`** (до 1 ГБ) или **модпак с Modrinth**. Программу и
версию Pano определяет сама. Никогда не импортируйте папку, сервер которой ещё работает.

> Сервер за прокси обычно работает с `online-mode=false` — держите его недоступным из интернета,
> иначе любой сможет зайти под любым именем.

## Настройки сервера {#server-settings}

Изменения применяются при следующем запуске.

- **Запуск:** версия Java, память, порт, аргументы JVM, **Запускать вместе с Pano**, **Перезапуск
  после сбоя**.
- **Память** — это вся память сервера, а не только куча Java: куча получает её за вычетом доли для
  самой JVM (25 %, от 384 МБ до 1 ГБ) — например, 2048 МБ дают кучу 1536 МБ. В среде Docker это
  лимит контейнера. Куча начинается с четверти своего максимума и растёт по мере надобности; на
  Java 12+ простаивающий сервер возвращает память. Ваши собственные аргументы JVM по-прежнему важнее.
- **Server properties:** форма для `server.properties`. Записываются только изменённые вами ключи;
  остальное в файле остаётся как есть.
- **Java:** в режиме **Автоматически** — самая младшая версия, которую поддерживает эта версия
  Minecraft: 25 для 26.1+, 21 для 1.20.5–1.21, 17 для 1.17–1.20.4, 16 для 1.16.5, 8 для более
  старых. Недостающую Java узел скачивает сам.
- **Опасная зона → Сменить ПО / Переустановить:** переход на другую программу или версию с
  сохранением миров, плагинов и конфигурации там, где они подходят. Сначала делается резервная
  копия, а неудачная смена откатывается. Нужны право **Создание серверов** и ваш пароль.
- **Убрать сервер:** у управляемого сервера удаляет его папку **и его резервные копии**. Привязанный
  сервер только убирается из Pano.

## Если что-то пошло не так {#troubleshooting}

- **Узел остаётся офлайн** — локальному узлу нужна Java 17+ (`LOCAL_NODE_JAVA_MISSING`); задайте
  `local-node.java-path`, если Pano не может её найти. В остальных случаях смотрите
  `pano-node.log`.
- **Установка не удалась** — узлу нужен доступ в интернет к сайтам загрузки и свободное место на
  диске.
- **Сервер показывает CRASHED** — ошибка есть в его консоли. Код выхода `137` означает, что его
  убили снаружи, обычно из-за нехватки памяти.
- **Порт занят** — смените его на вкладке **Запуск** или оставьте поле пустым, и узел выберет
  свободный.
